# Dynamic To-Do List App

A simple and interactive To-Do List application built using HTML, CSS, and JavaScript with DOM Manipulation.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Responsive and clean UI
- Real-time DOM updates

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation

## Project Structure

todo-list-app/
│── index.html
│── README.md

## How to Run

1. Download or clone the repository
2. Open the project folder in VS Code
3. Open `index.html` in browser

OR use Live Server extension in VS Code.
